# Scripts du dépôt

`check-repository.mjs` vérifie la présence d'un README dans chaque dossier maintenu et les liens relatifs Markdown. Lancer `npm run repo:check` depuis la racine.

`github/` contient la préparation du dépôt distant, ses réglages, labels et issues. Ces outils restent en prévisualisation tant qu'une application explicite n'est pas demandée.
