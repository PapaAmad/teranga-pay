# Textes de l’interface

`fr.ts` centralise les textes français du socle, y compris les boutons et titres de navigation. Ajouter les prochains textes ici plutôt que dans le JSX.

T09 mettra en place le système de traduction et la sélection de langue ; T33 apportera le wolof relu par des locuteurs. Ce fichier seul ne constitue pas le système i18n complet.
