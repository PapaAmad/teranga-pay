# Écrans

Les écrans assemblent les composants React Native et appellent la navigation typée. Le hook `useTranslation` lit les clés de `../translations` ; un changement de langue actualise le texte sans réinitialiser les champs ni la route active.

`HomeScreen` affiche l’état du prototype dans un contenu défilable et ouvre `AboutScreen` ou `DesignSystemScreen` avec les boutons de marque. La galerie T08 présente l'identité proposée et les états des composants ; ses interactions restent locales et fictives. `AboutScreen` décrit le projet dans un contenu défilable et permet de revenir. Les écrans métier restent à construire. PAN porte les écrans et T09 ; Salam relit. Lancer `npm run mobile` depuis la racine.
