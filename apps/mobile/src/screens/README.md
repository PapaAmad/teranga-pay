# Écrans

Les écrans assemblent les composants React Native et appellent la navigation typée. Les textes proviennent de `../translations/fr.ts`.

`HomeScreen` affiche l’état du prototype dans un contenu défilable et ouvre `AboutScreen` ou `DesignSystemScreen` avec les boutons de marque. La galerie T08 présente l'identité proposée et les états des composants ; ses interactions restent locales et fictives. `AboutScreen` décrit le projet et permet de revenir. Les écrans métier restent à construire. Lancer `npm run mobile` depuis la racine.
