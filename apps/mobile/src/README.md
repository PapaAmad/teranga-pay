# Code de l’application

Le code TypeScript de l’interface vit ici. `navigation/` assemble les écrans, `screens/` contient les vues et `translations/` centralise les textes. `App.tsx` fournit les contextes partagés et `index.ts` enregistre l’application auprès d’Expo.

Ajouter les futurs dossiers de composants, de services et de fonctions lorsqu’ils auront une première implémentation. Chaque dossier source conserve un README court.
