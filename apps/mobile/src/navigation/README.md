# Navigation

`RootNavigator.tsx` déclare la pile native et ses titres. `types.ts` liste les routes et leurs paramètres pour que TypeScript vérifie chaque changement d’écran.

Le socle contient `Home`, `About` et la galerie T08 `DesignSystem`. Les parcours wallet seront ajoutés aux tâches prévues, sans logique de paiement dans le navigateur. Lancer `npm test -- --ci` depuis la racine pour vérifier la navigation.
