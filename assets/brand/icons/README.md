# Icônes Teranga Pay | proposition T08

Dessins originaux du projet, sans Lucide ni catalogue d'icônes. `paths.json` est la source partagée entre le rendu SVG mobile et la planche de marque. Les fichiers SVG sont des exports consultables et modifiables.

Grille de 24 unités, trait de 2 unités, terminaisons et angles arrondis. Les ouvertures et les courbes d'entrée reprennent le vocabulaire du signe de marque. L'icône visible fait 24 unités ; la cible interactive mesure au moins 48 dp. Garder un libellé pour les actions financières.

PAN dessine, Salam relit. Après une modification des tracés, `npm run brand:icons` régénère les SVG ; `npm run test:tooling` contrôle leur cohérence avec le rendu natif. Consulter la [charte](../../../docs/design/charte.md). Les formes restent proposées à la relecture et aux essais de reconnaissance.
