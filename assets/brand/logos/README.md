# Logos Teranga Pay | proposition T08

Sources vectorielles éditables du monogramme entre T et P, direction B « Le courant commun », retenue par PAN après échange avec Salam le 5 novembre 2026. Les trois pistes restent visibles dans la [planche de recherche](../exploration.html). Les deux modules évoquent un lien et une circulation ; cette lecture n'est pas un résultat de test utilisateur. `mark.json` partage le tracé avec le mobile.

`logo-principal.svg` contient le signe et le logotype vectorisé. `logo-inverse.svg` sert aux fonds profonds. `symbole.svg` et `symbole-mono.svg` servent aux petits formats. `app-icon.svg` prépare une icône d'application ; le choix artistique est acquis, sa vérification sur appareil reste distincte. Les variantes d'exploration A/C autour du choix B sont dans `directions.svg`.

Les contours du logotype proviennent de Manrope Bold, dont la police originale et la licence OFL sont conservées dans `../fonts`. Les autres formes sont dessinées pour ce projet. PAN crée, Salam relit ; la validation technique reste distincte du choix de direction. Voir la [charte](../../../docs/design/charte.md). Commande utile : `npm run repo:check`.
