# Notes de décision

Une note garde la raison d'un choix pour l'autre membre et les agents. Son auteur est le responsable de la tâche ; l'autre membre relit. Les décisions communes, notamment T10/T11, se discutent à deux.

| Note                               | Sujet                             | État                                                       |
| ---------------------------------- | --------------------------------- | ---------------------------------------------------------- |
| [0001](0001-structure-du-depot.md) | Organisation du dépôt jusqu'à T07 | Proposition implémentée localement, à relire               |
| [0002](0002-visibilite-privee.md)  | Dépôt et Project privés           | Instruction de PAN appliquée au dépôt ; Project à vérifier |

Pour la prochaine note, utiliser `0003-sujet-court.md` et préciser : date, tâche, état, problème, choix, solutions écartées et conséquences. Une décision proposée n'est pas une validation de l'autre membre. Mettre à jour l'index lorsqu'une note est ajoutée ou remplacée.
