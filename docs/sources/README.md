# Documents de référence

Ces PDF fournis par l'équipe constituent les sources de travail. Ils ont été déplacés dans ce dossier sans modification de leur contenu. Salam porte leur évolution ; PAN s'appuie sur eux pour le dépôt et l'interface.

| Document                                                         | Version                | À consulter pour                                             |
| ---------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------ |
| [Document de conception](Teranga_Pay_Document_de_conception.pdf) | 1.0, octobre 2026      | Produit, parcours, architecture, sécurité, périmètre du MVP. |
| [Plan d'équipe et règles](Teranga_Pay_Plan_equipe_et_regles.pdf) | 1.0, 1er novembre 2026 | Responsabilités PAN/Salam, T01 à T40, jalons, règles GitHub. |

Le [suivi du socle](../planning/suivi-t01-t07.md) précise ce qui a effectivement été préparé. La [feuille de route](../planning/roadmap.md) reprend les prochaines étapes sans les déclarer accomplies.

Les PDF conservent leur demande d'origine d'un dépôt public. PAN a choisi le 2 novembre 2026 de garder le dépôt et le tableau privés : la [décision 0002](../decisions/0002-visibilite-privee.md) consigne cet écart sans modifier les sources.

Les chiffres économiques, tarifs, réglementations et horaires externes mentionnés dans les PDF restent à vérifier avant publication ; ils ne constituent pas une configuration du projet.
