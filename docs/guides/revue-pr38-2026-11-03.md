## Vérifications supplémentaires

- Un marqueur canonique de tâche reste prioritaire lorsqu'un utilisateur renomme son issue. Le titre sert seulement de repli sans marqueur ; plusieurs marqueurs distincts provoquent un arrêt avant écriture.
- Les champs du Project sont aussi paginés : un champ Status sur une page suivante ne doit pas entraîner la création d'un second champ de suivi.
- Les archives ne sont ni réactivées ni ajoutées à nouveau lors de deux relances successives.
- Les jonctions de dossiers sont testées indépendamment du test Windows de lien fichier, afin qu'un skip de permission ne masque pas leur vérification.
- Les extensions Markdown classiques sont analysées dans toutes les casses. Les formats documentaires réservés suivent les formats pris en charge par GitHub.

## Limites et preuves

Un titre résiduel trop long doit être raccourci, sans contourner la limite de l'équipe. Voir le [générateur officiel de Dependabot](https://github.com/dependabot/dependabot-core/blob/main/common/lib/dependabot/pull_request_creator/message_builder.rb#L275).
