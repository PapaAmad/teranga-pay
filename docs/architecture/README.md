# Architecture

Ce dossier décrit l'architecture cible et ses frontières. Salam porte la logique wallet, le serveur et Lightning ; PAN porte l'interface et la passerelle simulée. Le contrat partagé sera fixé ensemble en T11.

Lire la [vue d'ensemble](vue-ensemble.md) pour consulter les diagrammes Mermaid de l'architecture cible et du futur réseau regtest, puis distinguer le socle actuel des services futurs. Les décisions validées se trouvent dans [decisions](../decisions/README.md) ; les PDF d'origine dans [sources](../sources/README.md).

Les schémas sont écrits dans des blocs Markdown `mermaid`, rendus par GitHub, sans icônes. Ajouter ici les flux, conventions d'erreur et descriptions de stockage à mesure qu'ils sont réellement définis. Aucun choix de SDK ou contrat d'API n'est imposé par un dossier réservé.
