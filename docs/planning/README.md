# Planning et avancement

Salam porte le planning général ; PAN prépare le suivi du socle et les outils GitHub. Chaque responsable actualise les preuves de sa tâche après vérification et l'autre membre relit.

- [Suivi T01 à T07](suivi-t01-t07.md) : ce qui est préparé localement et ce qui attend une action ou une preuve distante.
- [Feuille de route T01 à T40](roadmap.md) : phases, responsables, dates et jalons du plan d'équipe.
- [Publication GitHub](publication-github.md) : état vérifié du dépôt privé, de l'accès, des PR et de la configuration distante.

Ces documents complètent le tableau GitHub Projects, qui doit rester privé comme le dépôt. Une issue, une branche et une PR doivent correspondre à une tâche ; un fichier de préparation ne signifie pas que la tâche distante a été effectuée.
